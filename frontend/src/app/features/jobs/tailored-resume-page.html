How it is built

  • Only lines you confirmed, from your jobs, projects, and education. Nothing is copied from the posting.
  • Lines that cover more of the posting come first. Every job stays, in date order, and gets a line before any project does.
  • Up to three projects that show the most of the posting get their own section, two lines each, even when a job shows the same thing.
  • Skills you kept use the posting's spelling only when it is the same product, like PostgreSQL for Postgres. Skills you don't have are never added.
  • One page, one column. The PDF's text is read back to check it and to score it again.
  • Each build is saved as its own version and never changes afterwards.
